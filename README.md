## About Connection Canvas

Connection Canvas is a lightweight static website designed to present the public-facing pages an iOS app needs in one simple location. It is built around GitHub Pages hosting and can be used to publish a landing page, privacy policy, and support page without requiring a dynamic backend.

The project is centered on clarity and accessibility for app users, store review links, and support workflows. It is especially useful when you want a single web presence that points visitors to the right App Store Connect resources while keeping the content easy to maintain as static HTML.

## FAQ

**Where should the site be hosted?**  
It is designed for GitHub Pages, but any static host can serve the same files.

**How do I update the support or privacy pages?**  
Edit the HTML content in the repository, then push the changes and republish.

**Can I change the app links?**  
Yes. Replace the App Store Connect or related URLs in the source pages.

**What if the live page does not update right away?**  
Check the GitHub Pages publishing settings, confirm the latest commit was pushed, and refresh after the site rebuild completes.

**Is this a dynamic application?**  
No. It is a static website made for app support and landing content.
